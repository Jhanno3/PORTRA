# PORTRA

Sitio web de PORTRA Studio — estudio creativo independiente de branding, cultura y experiencias. Identidad editorial minimalista y cinematográfica.

Proyecto [Next.js](https://nextjs.org) (App Router, TypeScript, Tailwind CSS).

## Desarrollo

```bash
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) para ver el resultado. La página principal se edita en `src/app/page.tsx`.

## Estructura

- `src/app/` — rutas y layouts (App Router)
- `src/components/` — componentes reutilizables
- `public/` — assets estáticos

## Deploy

La forma más simple de desplegar esta app es con [Vercel](https://vercel.com/new), los creadores de Next.js.
